
# Omarchy Denver Fire Lookout theme

An Omarchy theme based on my overnight stays at the Mestaa’ėhehe (pronounced mess-taw-HAY) Mountain Fire Lookout
that overlooks Denver, Colorado, USA.

Based on the [Omarchy instructions](https://omarchy.org/manual/making-your-own-theme).
Started with a copy of the kanagawa theme in ```/usr/share/omarchy/themes/kanagawa``` to the
user theme area in ```$HOME/.config/omarchy/themes/```

# Installation

```bash
omarchy-theme-install https://github.com/nilesoien/omarchy-denver_fire_lookout-theme
```
